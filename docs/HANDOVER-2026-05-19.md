## Conventions & gotchas

### Local-only work

User explicitly said *"don't need to push, work local"* mid-session.
**Do not `git push` without re-asking.** The 15 commits ahead of
origin are deliberate. The CI workflow will fire when they're
eventually pushed, but that's the user's call.

### Post-commit hook auto-syncs the kanban

`.git/hooks/post-commit` (installed this session) runs
`kanban-sync _kanban.md` after every commit that touched
`_kanban.md`. **You'll see "Sync complete!" in commit output when
this fires.** No manual sync needed.

### Kanbanger sync is one-way (local → GitHub)

Cards moved on github.com don't flow back. The local `_kanban.md` is
authoritative. If you see drift, the local file wins.

### REVIEW gate discipline

Per `LLM_GUIDANCE.md` and the kanbanger-partymix docs:
**AI agents never move work directly to DONE.** Move to REVIEW; human
approves REVIEW → DONE. There are currently 9 items sitting in REVIEW
from this session awaiting user sign-off.

### Sensitive files

`tokens.json`, `client_secret.json`, `.env` — **never edit, never
commit, never print contents to chat**. Gitignore covers them. If
you need a token value (e.g. to verify auth), use Python with
`load_dotenv` and print only `len()` or boolean presence — never
the value itself.

### Whisper currently requires a Python venv

The `WhisperExtractor.ts` spawns `python whisper_extractor.py`.
Until Tier 3's de-Python Whisper item ships, the user needs a
Python venv with `openai-whisper` installed. Don't claim "TS-only"
artifact yet.

### `gh` CLI is at the Windows install path, not bash PATH

When using `gh` from the Bash tool: `"/c/Program Files/GitHub
CLI/gh.exe"` — `which gh` from MINGW64 bash returns nothing despite
the binary being installed. This bit me twice this session.

### Ink components need a TTY

`useInput` from Ink panics without a real terminal. Running
metube commands via the Bash tool causes React reconciler errors
deep in the stack. To verify auth or test the API, write a small
direct-script that uses `googleapis` directly — don't try to
invoke `metube playlist discover` from a non-TTY shell.
